# SIDSight

## Agrifood Policy Explorer for Small Island Developing States

SIDSight is an independent portfolio project exploring selected agrifood, economic, digital and data-related issues across Small Island Developing States (SIDS).

The project brings together a small set of public indicators and policy information to look at three practical questions:

* What do selected indicators tell us about different SIDS contexts?
* What information would be useful when preparing for a country-level policy discussion?
* How do these issues connect with existing FAO priorities, programmes and SIDS-focused initiatives?

### Project structure

**SIDS Overview**
A comparative view of selected SIDS across the Pacific, Caribbean and Atlantic, Indian Ocean and South China Sea (AIS) regions.

**Country Brief**
A concise country-level view combining key indicators, data availability and selected policy considerations.

**FAO Connections**
A thematic view linking country issues with relevant FAO SIDS priorities, dialogue topics and programme areas.

### Tools

* Power BI for data exploration and visualization
* ArcGIS Online for a simple interactive map
* Excel for data preparation
* GitHub for project documentation and version tracking

### Scope

The first version covers a small selection of SIDS across the three main regions. The project is intended as a practical demonstration of policy research, data visualization and knowledge management rather than a comprehensive assessment of SIDS.
